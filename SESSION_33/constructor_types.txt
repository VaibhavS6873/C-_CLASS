        Default constructor:

        A constructor DEFINED BY PROGRAMMER WHICH DOES NOT HAVE 
        ANY EXPLICIT FORMAL PARAMETER IS CALLED AS A DEFAULT CONSTRUCTOR 

        class C 
        {
            public: 
    
                C()
                {
                    // Body may be empty or 
                    // it may contain any length of code 
                }
        }

        Parameterized constructor: 
            If a constructor has at least one explicit, non-default formal parameter 
            then it is called as a parameterized constructor 

        class Date 
        {
            public: 
                Date(int dd=1, int mm=1, int yy=1970) : day(dd), month(mm), year(yy){} 
        };
